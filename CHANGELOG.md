# MPC Maid Updates

## Next Update


- Daily quests can now lucky-drop T1 boosters, and 7-day streaks reward T2/T3 random booster.
- `/slots` now feels like a real slot machine with Spin Again and Leave buttons.
- New `/relationship` command: build RP links with other members, including family, siblings, marriage, dating, and Besties.
- Relationship links need consent: the other user gets a private Accept or Decline request before anything is created.
- Use `/relationship view user` to privately check someone's relationship links.
- Stamina now gives a small XP bonus for every extra scene part it unlocks.
- Rumors feel more alive: scene, relationship, and pregnancy posts have more club flavor while keeping the useful info easy to read.
